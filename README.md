# 镜场 · 家庭白模

静态 Three.js 取景与角色摆位工具。直接托管 `dist`，无需编译或在线模型服务。

## 家庭场景

启动默认载入完整家庭，空间关系为「电视 → 沙发 → 沙发后方书房」，餐厨位于侧边。按参考照片估算比例，单位为米；书房地台高 0.32 m，两级踏步。此布局用于镜头背景与互动摆位，不是实测户型。

- 33 个独立可编辑对象，包含客厅、阅读区、餐厨、窗帘、书架、灯具和两只猫。
- 在「家庭取景」中切换总览、沙发看书房、电视区、书房、餐厨、猫咪低机位。
- 外墙从室外看会让开，室内取景保留；外墙和顶面也可以单独开关。
- 对象列表中的「人物比例参考」默认隐藏，点击空心圆显示，也可从添加对象菜单新增人物。
- 猫咪保留原有姿势、关节和 IK 编辑；人物是静态比例白模。
- 「落到下方表面」将对象向下放至地板、地台或家具表面；先把对象抬到目标表面上方再使用。
- 保存工程保留布局、角色姿势、机位和参考图。JSON 格式版本 4，兼容读取旧版本 2、3。
- 可导出干净 PNG 或镜头参考素材包；当前网页用于静态分镜摆位，不输出角色动画视频。

## 本地使用

在此目录执行 `python3 -m http.server 8767 --directory dist`，打开 `http://localhost:8767`。不要直接双击 HTML。

检查：`node checks/home-check.mjs && node checks/rig-check.mjs`。

家居模型通过本地几何构建；书架的 144 本书采用 Three.js InstancedMesh 批量绘制，依据 [Three.js 官方说明](https://threejs.org/docs/pages/InstancedMesh.html)。不依赖外部 3D 资产。
